Microsoft Excel
Pivot Tables
Pivot Charts
Slicers & Filters
Data Cleaning and Formatting
Dashboard Design

📊 Project Insights

Identified top-performing movie genres based on ratings and revenue.
Analyzed year-wise movie release trends.
Compared highest-rated and highest-grossing movies.
Visualized genre distribution and performance patterns.
Enabled interactive filtering for better data exploration.
